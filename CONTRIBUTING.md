# Contributing to WGO

Bug reports, fixes and features are welcome.

- **Bugs and ideas:** open an [issue](https://github.com/ljacobsson/wgo-analytics/issues). For a larger change,
  open an issue before you write the code, so we can agree on the approach.
- **Pull requests:** keep each one focused on one change, and include tests where the code has them.
  [Local development](README.md#local-development) explains how to run the backend and dashboard locally. Each
  package's README lists its test commands.
