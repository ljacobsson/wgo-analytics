# Storylines

## A. "What's going on?" (built)

Device: a question with the input. The product's own name is the question; every feature answers it in one
more place. Form: object-to-object chain: each shot ends on the thing that opens the next (the question
mark's dot becomes a map ping, the script tag is zoomed through into the Overview, a click on **Create
trigger** opens Triggers, **View logs for this trace** opens Logs, the HDMI cable leads up to the office TV).

- First 2 s: "What's going on?" in giant type on the dashboard's own ground; the dot of the "?" pings cyan.
- Beats: question → live map → one script tag → Overview → Live → Goals/funnel → Errors → Triggers →
  OpenTelemetry → Traces → Logs → Metrics → MCP ("…What's going on?" asked again, answered) → Android widget
  → Raspberry Pi + office wall TV → your AWS account → end card.
- Look: the dashboard's ground #0a0a0f and its violet→cyan accent; real screens at 1.2–1.8×; two worlds that
  aren't the dashboard: a daylight office wall and a light chat client.
- Sound: silent (no music source signed in); see REVIEW.md.

## B. "The 14:00 incident" (not built)

A moment in someone's day: checkout complaints start at 14:00 and one on-call engineer follows a single
failing checkout from the phone widget's error count, through the trigger, the trace, the log and an MCP
answer, to the fix shown on the office TV. Tighter story, but leaves Goals and the SDK install out.

## C. "One wall" (not built)

One frame that rebuilds: the office TV is the only stage. Every feature is a kiosk screen rotating on the
wall, with the camera pushing in and out of the TV; the Pi boot is the opening. Bold, but every feature
reads at TV size, which costs legibility.
